What it is

A Brainfuck program works on a long row of bytes, all starting at zero, and a pointer to one of them. Every character that is not one of the eight commands is ignored, so comments need no marker.

It is the best-known example of a Turing tarpit: a language that can compute anything, but in which almost nothing is easy.

The eight commands

CommandWhat it does
>Move the pointer one cell right
<Move the pointer one cell left
+Add 1 to the current cell
-Subtract 1 from the current cell
.Print the current cell as a character
,Read one character into the current cell
[If the current cell is 0, jump past the matching ]
]If the current cell is not 0, jump back to the matching [

How it runs

Adding 72 one at a time to reach H would be slow to write, so the program starts with nested loops that multiply: eight times through the outer loop, four times through the inner one, adding 2, 3, 3 and 1 to four cells each time.
