What it is

INTERCAL was written in 1972 by two students, as a language with nothing in common with the languages of its day. Its name is short for “Compiler Language With No Pronounceable Acronym”. Where other languages tried to be convenient, INTERCAL was built to be inconvenient in every way it could think of, which is what makes it the first esoteric language.

It has no ordinary arithmetic: numbers are combined by interleaving and selecting their bits. It writes numbers out in Roman numerals. And it has a rule about manners: a statement may be marked PLEASE, and a program with too few of them is refused for not being polite enough, while one with too many is refused for grovelling.

This site runs a small part: arrays, number variables set from constants, output, and the politeness rule. The bit-interleaving operators, COME FROM and the rest are not run here.

The statements used here

StatementMeaning

The numbers in the array are not the letters. To print an array, INTERCAL takes each element away from the previous result (the first from 0, wrapping round at 256), then writes the result’s eight bits in reverse order and prints that character. The first element, 238, takes away from 0 to give 18, which is 00010010; read backwards, that is 01001000, or 72, which is H.

Now the politeness rule. The Hello World above has 16 statements, and 4 of them say PLEASE: a quarter, which is within the allowed range of between a fifth and a third. Take the four PLEASEs out and this site’s build gets E079 PROGRAMMER IS INSUFFICIENTLY POLITE. Put one on every statement and it gets E099 PROGRAMMER IS OVERLY POLITE. The build checks both of these every time it runs.
