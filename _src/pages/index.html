What makes a language esoteric

An esoteric programming language is built to make a point, not to be used at work: that eight commands are enough, that a program can be a painting, a recipe or a play, that code can be invisible, or that a language can fight its programmer.

Most of them can compute anything an ordinary language can. What they give up is ease. Brainfuck needs {{steps brainfuck}} steps to print one line; LOLCODE, which reads almost like English, needs {{steps lolcode}}, though one LOLCODE step does far more than one Brainfuck step (what counts as a step). Malbolge needs only {{steps malbolge}}, but no person wrote its program by hand: programs that work in Malbolge are found by searching, not written.

Scratch and HolyC are on the poster as controls. Scratch looks unusual too, with blocks instead of text, but it was designed to be easy for beginners. HolyC looks like C and behaves strangely, because one person, Terry A. Davis, built a whole operating system around it and shaped the language to fit. Neither makes the point the other thirteen make.
