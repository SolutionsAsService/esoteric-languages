**Critic: Provocateur (Shklovsky), R2**

**Anchor used:** Shklovsky, "Art as Technique": habitualization devours works, clothes, furniture; art exists to make the stone stony, by making form difficult and prolonging perception. Test: does the device make the reader perceive the language, or only recognise a new ornament?

**Observed in the work:**
- Brainfuck's field now sets the program above the tape it leaves (0 0 72 100 87 33 10 0, labelled H d W ! and a line feed). The reader sees the language's one real material, a row of cells, instead of its characters. That is defamiliarization: the text is no longer the object, the residue is.
- Malbolge's field shows the program before and after, "58 of its 64 characters rewritten as it ran", changed cells marked. The page repeats it as before/after rows. The unreadability is demonstrated, not asserted. Strongest device on the site.
- LOLCODE is set as a caption in impact-style type (HAI 1.2 / VISIBLE / KTHXBYE). The language's joke becomes the form. It is a genre quotation, thin, but the form is the content.
- Ook! is captioned "the Brainfuck program, in orangutan", with a pale grid of "Ook!". Weakest: the field is still text on yellow, but the caption does the estranging.
- Decline: the inner pages share one "How it runs" template. In malbolge-1280.png it is a before/after box plus a table, while lolcode-1280.png is code box plus run box. The content already differs in kind (mutation table versus loop), and the strangeness has moved into the poster, where the habit was worst.

**Verdict: PASS.** The poster devices are mechanisms drawn from each language's own behaviour, not decoration. The decline is acceptable. I cannot point to a concrete defect: the inner template is a stable frame, and the Malbolge and LOLCODE pages still differ in form where it matters.

**Requested change (one):** Make Ook! estranged by something computed, as the others are: for example, show the Ook! pairs aligned under the Brainfuck symbol each one stands for, so the substitution is visible rather than captioned.

**Statement of meaning:** Each language is shown doing the thing that makes it strange, so the eight fields read as eight perceptions rather than eight skins on one code box.

**One critic question:** If the reader sees Malbolge scramble itself, does the first-screen number "40 steps" now mislead, since it hides what those steps did to the page?
