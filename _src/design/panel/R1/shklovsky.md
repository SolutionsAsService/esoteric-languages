# R1 Critic: Provocateur (Shklovsky)

**Anchor used:** Viktor Shklovsky, "Art as Technique": habitualization devours works, clothes, furniture; art exists to make the stone stony, to increase the difficulty and length of perception.

**Observed in the work:**
- Mondrian grid for a site about programming: an expected reference. Mondrian-as-code is a stock gesture, and the Piet link (Piet is itself Mondrian-named) makes it motivated but not strange. The grid is seen, then filed away.
- The programs-as-images device is the real defamiliarization, but it works only in some fields. Whitespace (invisible characters made into faint, black and red bars), Piet (the program as colour columns), and Befunge (the string running backwards above a stack-height histogram) make the reader see a program as a thing. The Brainfuck, Ook!, Malbolge and LOLCODE fields are just monospaced text on a flat colour. That is a code screenshot, not a seeing. The huge step number (906, 98, 27, 1) is the best estrangement: it turns "Hello World" from a joke into a cost. Ook! and Brainfuck both read 906, which makes the reader see a sameness.
- Eight inner pages share one template (band, What it is, instructions, Hello World, How it runs, Sources). Whitespace and Malbolge show identical scaffolding: the same black bar, the same heading rhythm, the same table. The band alone varies. The template automatizes by the third page; the reader learns "skip to the table". The Malbolge page does vary a little in content (self-scrambling trace), but the form does not carry that difference. Whitespace's `[S][T][L]` listing is the only moment where a page's form changes with the language.

**Verdict:** PASS (no concrete defect; the automatization is a weakness, not a break).

**Requested change (one):** Let the "How it runs" section take a different form per language, drawn from that language's own strangeness, instead of one table. For example Malbolge shows the instruction cell mutating in place, and Whitespace shows the invisible file with the real characters left blank. Keep the template's order and cut the sections that repeat.

**Statement of meaning:** The poster makes code visible only where the language hides or scrambles it, and the template then returns every language to the same textbook page.

**Critic question:** If you removed the Mondrian bars, would the eight fields still tell the reader what is strange about each language, or is the grid doing the estranging that the programs should do?
