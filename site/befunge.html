Esoteric language

Befunge

The program is a grid; the instruction pointer can travel in four directions.

By Chris Pressey, 1993.

What it is

A Befunge-93 program is a grid of 80 by 25 characters. The instruction pointer starts at the top left moving right, and arrows turn it up, down, left or right. When it runs off one edge it comes back on the opposite one. Values live on a stack.

Befunge was designed to be as hard to compile as possible: the program can change its own grid while it runs, with p.

The commands this program uses

CommandWhat it does
"Start or stop string mode: until the next ", every character is pushed as its code
> < ^ vMove right, left, up or down from now on
:Duplicate the top of the stack
#Bridge: skip the next cell
,Pop a value and print it as a character
_Pop a value: move right if it is 0, left otherwise
@End the program

The full language also has arithmetic, a random direction (?), input, and g and p to read and write the grid itself.

Hello, World!

One line of 21 cells. It prints Hello, World! in 98 steps.

How it runs

The string "!dlroW ,olleH" is written backwards because a stack gives back the last thing pushed first: H comes off the top.

The bars in the band above count how often the instruction pointer passed each cell. The string cells are passed once, pushing the letters backwards; the six cells of the print loop >:#,_ are passed again and again, and # makes the pointer jump the cell after it on the way back.
