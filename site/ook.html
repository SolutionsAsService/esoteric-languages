What it is

Ook! has exactly the eight commands of Brainfuck, each written as a pair of the words Ook., Ook? and Ook!. Any Brainfuck program can be translated word for word, so the two run the same number of steps.

Its designer, David Morgan-Mar, also made Piet. The words are the Librarian’s, from Terry Pratchett’s Discworld.

Hello, World!

This is the Brainfuck program translated by the site’s build. It prints Hello World!↵ in 906 steps, exactly as Brainfuck does, and is 1059 characters long, ten times the original.

How it runs

Every pair of words turns back into one Brainfuck command, so the run is the same machine doing the same 906 steps. See how the Brainfuck version runs.
