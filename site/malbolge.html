Malbolge

Designed to be as hard to program as possible. Every instruction rewrites itself after it runs.

By Ben Olmstead, 1998.

(=<`#9]~6ZY32Vx/4Rs+0No-&Jk)"Fh}|Bcy?`=*z]Kw%oG4UUS0/@-ejc(:'8dcyd3<][b@Z|8)P_:4HvR${1xwqFKfzJYi">V#+<d*z·Hw··········-·j9····d!

What it is

Malbolge is named after Malebolge, the eighth circle of hell in Dante's Inferno. Its memory holds numbers in base 3, its only arithmetic is a deliberately strange operation on base-3 digits, and every instruction is scrambled through a substitution table as soon as it has run.

It was hard enough that the first working programs were not written by a person. They were found by a computer search.

The eight instructions

(cell + position) mod 94What it does
4Jump to the address stored where the data pointer points
5Print the accumulator as a character
23Read a character into the accumulator
39Rotate the value at the data pointer one base-3 digit right; copy it to the accumulator
40Move the data pointer to the address stored where it points
62The “crazy” operation on the accumulator and the value at the data pointer
81End
68, and anything elseDo nothing

Hello, World!

A program of 64 characters that prints Hello World!, without a comma, in 40 steps. The site prints what it really prints.

How it runs

Running it changes it. After the 40 steps, 58 of the program’s 64 characters are different. Changed characters are underlined; a dot is a value with no printable character.
