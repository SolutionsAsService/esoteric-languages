Esoteric language

FALSE

A tiny stack language with lambdas, made to have the smallest compiler possible.

By Wouter van Oortmerssen, 1993.

["Hello, World!"]!10,

What it is

FALSE is a stack language: numbers are pushed, and operators take their arguments off the stack and push the result. It also has lambdas, written in square brackets and kept on the stack until something applies them. It is small on purpose, and was written for the Amiga with a compiler of only 1024 bytes. Its design inspired Brainfuck.

True is −1 and false is 0. A one-letter name is a variable: x names it, : stores a value there and ; fetches it. A loop is a condition lambda, a body lambda and a #.

This site runs the core of the language: the stack, lambdas, variables, loops and printing. The programs here take no input.

The symbols used here

WrittenMeaning
5, 48Push the number
"text"Print the text
, .Print the top as a character, or as a number
$ %Duplicate the top, or drop it
+ - >Add, subtract, greater than
[ … ]A lambda: push the code without running it
!Run the lambda on top of the stack
#While: runs the condition lambda, then the body lambda, until the condition gives 0

Hello, World!

21 characters; it prints Hello, World!↵ in 5 steps: push the lambda, run it, print the text inside it, push 10, print that as a character, which is the newline.

How it runs

A loop, counting down from 5. It prints 54321↵ in 55 steps.

The condition lambda $0> copies the number and asks whether it is more than 0. The body $48+,1- copies it, adds 48 to turn it into a digit’s character code, prints that, and takes 1 off. When the number reaches 0 the condition fails, and % drops it. Most of the steps are the loop: every pass runs the condition and the body again.
