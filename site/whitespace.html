Whitespace

Only spaces, tabs and line feeds mean anything. Everything else is a comment.

By Edwin Brady and Chris Morris, 2003.

What it is

In Whitespace only three characters count: space, tab and line feed. Every other character is ignored, so a Whitespace program can hide inside the blank parts of a program in another language, or look like an empty file.

Like Befunge and Piet, it keeps numbers on a stack (a pile where the last number put on is the first taken off) and has a heap for numbers stored at an address.

It was released on 1 April. The band above draws this site's program with the invisible made visible: outlined bars are spaces, solid black bars are tabs, taller red bars are line feeds.

How instructions are spelled

Starts withGroupExamples used here
[Space]Stack[Space][Space] number: push it
[Tab][Space]Arithmeticadd, subtract, multiply, divide, modulo
[Tab][Tab]Heapstore and retrieve
[Line feed]Flow control[LF][LF][LF]: end the program
[Tab][Line feed]Input and output[Tab][LF][Space][Space]: print a character

Hello, World!

The site’s build writes this program from the sentence, then runs it: 195 characters, all invisible, 27 steps, and it prints Hello, World!. Below, each space is shown as [S], each tab as [T] and each line feed as [L]; the downloadable file contains only the real characters.

How it runs

The program decodes to 27 instructions: a push and a print for each of the 13 characters, then an end. Numbers are written in binary, with space for 0 and tab for 1.
