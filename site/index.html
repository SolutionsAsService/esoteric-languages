What makes a language esoteric

An esoteric programming language is built to make a point, not to be used at work: that eight commands are enough, that a program can be a painting, that code can be invisible, or that a language can fight its programmer.

Most of them can compute anything an ordinary language can. What they give up is ease. Brainfuck needs 906 steps to print one line; LOLCODE, which reads almost like English, needs 1, though one LOLCODE step does far more than one Brainfuck step (what counts as a step). Malbolge needs only 40, but no person wrote its program by hand: programs that work in Malbolge are found by searching, not written.

Scratch is on the poster as the control. It looks unusual too, with blocks instead of text, but it was designed to be easy for beginners. That is the opposite of the point the other seven make.
