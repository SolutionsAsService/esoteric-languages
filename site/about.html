About

How this site knows

Every program on the poster was run by the site’s own build, from the same file you can download.

Run them yourself

The interpreters are short Python files in _src/eso, written for this site. With Python 3 and, for Piet, the Pillow library:

The build writes every program to site/programs/, runs each one from that file, and stops with an error if any output or step count differs from what the pages say. It also generates the Whitespace and Piet programs, and checks that the Piet PNG reads back as the program it drew.

What counts as a step

LanguageOne step isHello, World!
Brainfuck, Ook!One command executed (a jump counts once)906
BefungeOne cell the instruction pointer executes; a cell skipped by # is not counted98
WhitespaceOne decoded instruction27
PietOne move from one colour block to another26
MalbolgeOne instruction, including those that do nothing40
LOLCODEOne statement, not counting HAI and KTHXBYE1
ChefOne method sentence executed; a loop’s opening and closing sentences count each time they are reached14
ShakespeareOne spoken sentence, including one skipped by “If so” or “If not”; stage directions and scene headings do not count27
UnlambdaOne function application (one backtick evaluated)14
FALSEOne token executed: a number, string, operator or lambda; a loop’s tokens count every time round5
INTERCALOne statement executed16
RockstarOne statement executed; a loop’s condition counts each time it is tested2
ScratchNot run; the poster counts blocks2 blocks

The counts are not comparable across languages: one LOLCODE step is a whole statement, one Brainfuck step a single character. Read each number as what that program cost in its own language, not as a ranking. The outputs differ slightly too: the Brainfuck, Ook! and Malbolge programs print Hello World! without the comma, as they were written, and the Chef recipe prints Hello world! and the INTERCAL program Hello, world!, as their usual examples do.

The design

The grid of black bars is Piet Mondrian's, the painter Piet is named after. Every colour on the poster comes from the Piet specification's 20 colours. Each field on the home page shows the real program, drawn from its own file. The design decisions and reviews are recorded in the design log.

Facts about the languages link to the Esolang wiki, Wikipedia or the designers' own pages. Esoteric languages are a community hobby, and the Esolang wiki lists thousands more.
